What this report measures

Selection proof: verbose llama-bench output must say llama_prepare_model_devices: using device ..., and tensor/compute buffers must name the same device. OpenVINO must report using device GPU; otherwise it is a CPU comparison.
  • Prompt tokens/s measures prompt ingestion and is sensitive to batch size and memory bandwidth.
  • Generation tokens/s measures autoregressive decode and is the main interactive-chat metric.
  • Wall time includes model initialization and benchmark execution; use it to spot slow startup or compilation.
  • Peak RSS, model buffer, free device memory, and offloaded layers expose memory pressure and accidental CPU fallback.
  • Missing bars mean the case failed, timed out, or produced no valid llama-bench JSON result. Expand its diagnostic entry below.
